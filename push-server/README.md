# שרת התראות לפלס (palas-push)

שרת קטן שרץ ב-Cloudflare Workers. התפקיד היחיד שלו הוא "להעיר" את האפליקציה באייפון בזמנים שהיא ביקשה, בעזרת Web Push.

## מה השרת שומר ומה לא

השרת שומר רק:

- מזהה אקראי של המכשיר, ו-hash של הסיסמה הסודית שלו (לא את הסיסמה עצמה).
- כתובת ההרשמה להתראות (Push Subscription) שהדפדפן יצר.
- רשימת זמנים שבהם צריך לשלוח התראה, וסוג כל זמן: `morning` (בוקר) או `evening` (ערב).

השרת **לא** מקבל ולא שומר שום תוכן של משימות: לא כותרות, לא שמות ולא הערות. ההודעה שנשלחת לטלפון מוצפנת ומכילה רק את סוג ההתראה ואת הזמן. הטקסט שמופיע בהתראה נבנה בטלפון עצמו, מתוך המידע שכבר שמור בו.

## הקמה (פעם אחת)

כל הפקודות רצות מתוך התיקייה `push-server`, בחלון טרמינל.

1. פותחים חשבון חינמי ב-Cloudflare בכתובת https://dash.cloudflare.com/sign-up
2. מתקינים את הכלים (פעם אחת):

   ```
   npm install
   ```

3. מתחברים לחשבון (ייפתח דפדפן לאישור):

   ```
   npx wrangler login
   ```

4. יוצרים את מסד הנתונים:

   ```
   npx wrangler d1 create palas-push
   ```

   בפלט מופיע `database_id`. מעתיקים אותו לקובץ `wrangler.toml`, במקום `REPLACE_WITH_D1_ID`.
5. יוצרים את הטבלאות:

   ```
   npx wrangler d1 execute palas-push --remote --file=schema.sql
   ```

6. בודקים את `wrangler.toml` בחלק `[vars]`:
   - `ALLOWED_ORIGINS` הוא הכתובת שממנה האפליקציה נטענת, בלי נתיב. כרגע: `https://dudutal-dev.github.io`
   - `VAPID_SUBJECT` הוא כתובת האפליקציה המלאה. כרגע: `https://dudutal-dev.github.io/peles/`. אפל דוחה התראות אם הערך הזה אינו כתובת `https://` תקינה.
7. יוצרים מפתחות הצפנה להתראות ושומרים אותם כסוד ב-Cloudflare:

   ```
   node scripts/setup-vapid.mjs
   ```

   הסקריפט מדפיס רק את המפתח הציבורי. המפתח הפרטי נשלח ישירות ל-Cloudflare, ולא מודפס ולא נשמר בשום קובץ.
   אם מופיעה שגיאה שה-Worker עדיין לא קיים, מבצעים קודם את שלב 8 וחוזרים לשלב הזה.
8. מעלים את השרת:

   ```
   npx wrangler deploy
   ```

   בהעלאה הראשונה ייתכן שתתבקשו לבחור שם לתת-דומיין `workers.dev`.
9. מעתיקים את כתובת השרת שמופיעה בסוף הפלט (למשל `https://palas-push.<השם-שלכם>.workers.dev`) ומזינים אותה בהגדרות של האפליקציה.

## חשוב לדעת

- **אל תריצו שוב את `setup-vapid.mjs`** אלא אם צריך להחליף מפתחות. הרצה נוספת מחליפה את המפתחות, וכל מכשיר רשום יפסיק לקבל התראות עד שיירשם מחדש מתוך האפליקציה.
- אסור להכניס סודות לקבצים בתיקייה הזו, כי הקוד נמצא במאגר ציבורי. הסוד היחיד, `VAPID_PRIVATE_JWK`, נשמר רק ב-Cloudflare.
- השרת בודק כל 5 דקות אם הגיע זמן לשלוח התראה. לכן התראה יכולה להגיע באיחור של עד כ-5 דקות.
- מספר המכשירים מוגבל ל-10 (`MAX_DEVICES` ב-`wrangler.toml`).

## עלות

השימוש הצפוי קטן בהרבה מהמכסה החינמית של Cloudflare. נכון לכתיבת שורות אלה, המכסה כוללת 100,000 בקשות ביום ל-Workers, ו-5 מיליון קריאות ו-100,000 כתיבות ביום ל-D1. השרת הזה צורך כמה מאות פעולות ביום.

## למפתחים

```
npm test
npx tsc --noEmit
```

ממשק ה-API:

- `GET /vapid-public-key` מחזיר את המפתח הציבורי.
- `PUT /devices/:id` רושם מכשיר או מעדכן אותו, יחד עם לוח הזמנים שלו.
- `DELETE /devices/:id` מוחק מכשיר.
- `POST /devices/:id/test` שולח התראת בדיקה מיד.

כל הבקשות אל `/devices` דורשות כותרת `Authorization: Bearer <secret>`.
