# פלס — כלי העבודה של הלשכה

אפליקציית PWA לנייד עבור מנהלת הלשכה של ראש מינהל תשתיות ובינוי: משימות מוקשרות-הקשר, מעקב "ממתין לתגובה", שגרת בוקר ומסך "בוקר טוב".
החלטות והנחות: [`docs/decisions.md`](docs/decisions.md).

## הרצה

```bash
npm install
npm run dev
```

| פקודה | מה עושה |
|---|---|
| `npm run dev` | שרת פיתוח (http://localhost:5173) |
| `npm run build` | בדיקת טיפוסים + build לייצור בתיקיית `dist/` |
| `npm run preview` | הרצת ה-build מקומית (כולל service worker ועבודה בלי רשת) |
| `npm test` | בדיקות יחידה (Vitest) |
| `npm run type-check` | TypeScript בלבד |
| `npm run icons` | ייצור מחדש של אייקוני האפליקציה |

בשרת הפיתוח אפשר לטעון נתוני הדגמה מהקונסול של הדפדפן: `await __lishkaDemo()`, ולנקות: `await __lishkaReset()`.

## מה יש בשלב א'

- **קליטה מהירה** מהכפתור שבמרכז: שורה אחת, הקלדה קולית, וזיהוי אוטומטי של `מחר` / `עד יום חמישי` / `עד 17.9` / `#תגית` / `@שם_גורם`. אפשר לבטל כל זיהוי.
- **מסך בוקר**: שגרת היום, פגישות היום, מה דורש טיפול, ומה נקלט ומחכה למיון.
- **ממתין לתגובה**: ממוין לפי כמה ימים זה תקוע, עם סינון "לנדנד" ו"מעל שבוע", ותצוגה לפי גורם.
- **משימות**: היום, חורג, לפי הקשר, הכל, חיפוש ("מה קורה עם...") וסינון לפי תגית.
- **פרטי משימה**: סטטוס, אחריות, תאריך יעד, תזכורת לפני/אחרי המועד, "דחוף לי" מול "ראש המינהל מחכה", הקשר, מקור, תגיות והערות. הכל נשמר אוטומטית.
- **עבודה בלי רשת** מלאה, שמירה מקומית ב-IndexedDB, גיבוי ושחזור לקובץ JSON.

## מבנה

```
src/
  domain/     לוגיקה טהורה בלי UI: טיפוסים, תאריכים, פענוח קליטה, תצוגות, שגרה
  data/       Dexie/IndexedDB, repositories, גיבוי, נתוני הדגמה
  features/   קליטה, משימות, שגרה, פגישות
  screens/    ארבעת המסכים הראשיים
  ui/         רכיבים משותפים: Sheet, Toast, Segmented, EmptyState
  app/        App, ניתוב hash, סרגל ניווט
  pwa/        service worker, התקנה, אחסון קבוע
  styles/     אסימוני עיצוב ו-CSS
build/        תוסף Vite שמייצר את sw.js
tests/        בדיקות יחידה ו-repository (fake-indexeddb)
```

שכבת הנתונים מופרדת מה-UI, וכל רשומה נושאת `updatedAt` ו-`deletedAt`, כדי שמעבר לסנכרון מול שרת בשלב ב' לא ידרוש שכתוב.

## התקנה בטלפון

Service worker והתקנה למסך הבית דורשים HTTPS. צריך להעלות את תיקיית `dist/` לאחסון סטטי כלשהו (למשל Netlify, Cloudflare Pages, GitHub Pages, או שרת פנימי של הארגון). רק הקוד עולה לשם; הנתונים נשארים במכשיר.
