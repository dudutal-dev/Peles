# פלס — כלי העבודה של הלשכה

אפליקציית PWA לנייד עבור מנהלת הלשכה של ראש מינהל תשתיות ובינוי: משימות מוקשרות-הקשר, מעקב "ממתין לתגובה", ישיבות, אירועים, גורמים ושגרת בוקר.

- **האפליקציה:** https://dudutal-dev.github.io/Peles/ (נפרסת אוטומטית מ-`main`)
- **מדריך למשתמש:** [`docs/user-guide.md`](docs/user-guide.md), וגם בתוך האפליקציה
- **החלטות והנחות:** [`docs/decisions.md`](docs/decisions.md)

## הרצה

```bash
npm install
npm run dev
```

| פקודה | מה עושה |
|---|---|
| `npm run dev` | שרת פיתוח (http://localhost:5173) |
| `npm run build` | בדיקת טיפוסים (אפליקציה + service worker) ו-build לייצור בתיקיית `dist/` |
| `npm run preview` | הרצת ה-build מקומית (כולל service worker ועבודה בלי רשת) |
| `npm test` | בדיקות יחידה (Vitest) |
| `npm run type-check` | TypeScript בלבד |
| `npm run icons` | ייצור מחדש של אייקוני האפליקציה |

בשרת הפיתוח אפשר לטעון נתוני הדגמה מהקונסול של הדפדפן: `await __lishkaDemo()`, ולנקות: `await __lishkaReset()`.

## מה יש

**שלב א'**
- קליטה מהירה עם זיהוי `מחר` / `עד יום חמישי` / `עד 17.9` / `#תגית` / `@שם_גורם` והקלדה קולית.
- מסך בוקר, ממתין לתגובה (לפי ימי המתנה, לנדנד), משימות (היום, חורג, לפי הקשר, הכל, חיפוש).
- עבודה בלי רשת, שמירה מקומית ב-IndexedDB, גיבוי ושחזור.

**שלב ב'**
- **ישיבות:** תיעוד תוך כדי ("מי התחייב למה עד מתי" הופך למשימה), חלוקת אחריות, שיתוף סיכום, קישור דו-כיווני.
- **אירועים:** checklist מוכן לפי סוג (בהשראת clalit-event-planner) עם לו"ז שנדחס לזמן שנשאר, שלושה מודלי תקציב, מקום פנימי מול חיצוני.
- **גורמים:** מה פתוח מול כל גורם, חיוג ומייל, והצעה לשמור שמות שמופיעים במשימות.
- **התראות Push** לאייפון דרך [`push-server/`](push-server/README.md): השרת יודע רק מתי להעיר, הטקסט נבנה בטלפון.
- **מדריך למשתמש** בתוך האפליקציה.

## מבנה

```
src/
  domain/     לוגיקה טהורה בלי UI: משימות, ישיבות, אירועים, גורמים, התראות, תאריכים
  data/       Dexie/IndexedDB (עם שדרוג גרסאות), repositories, גיבוי, נתוני הדגמה
  features/   קליטה, משימות, ישיבות, אירועים, גורמים, שגרה, התראות
  screens/    מסכים ראשיים, הגדרות ומדריך
  sw/         service worker (נבנה בנפרד, tsconfig.sw.json)
  pwa/        רישום, התקנה, אחסון, לקוח Push
  ui/         רכיבים משותפים
  app/        App, ניתוב hash, סרגל ניווט
build/        תוסף Vite שבונה את sw.js עם רשימת precache
push-server/  Cloudflare Worker לתזמון Web Push (פרויקט נפרד)
tests/        בדיקות יחידה ו-repository (fake-indexeddb)
```

## התראות

כדי להפעיל התראות צריך לפרוס את `push-server/` (הוראות ב-[README שלו](push-server/README.md)), ולשים את כתובת ה-Worker ב-`.env.production`:

```
VITE_PUSH_URL=https://palas-push.<account>.workers.dev
```

כל עוד הכתובת ריקה, מסך ההגדרות מציג שהשרת עוד לא חובר.
